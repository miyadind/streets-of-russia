Sprite Edge Cleaner

Локальный инструмент для пакетной очистки белой каймы у PNG-спрайтов. Файлы не отправляются в интернет: обработка идёт прямо в браузере.

Перетащи PNG сюда Можно файлы или целую папку. Также можно выбрать папку кнопкой ниже.
Для сохранения папкой нужен Chrome или Edge. Браузер спросит, куда писать файлы. Внутри выбранной папки будет создана папка cleaned-sprites.
